The same starting point—“a pelican riding a bicycle”—can lead to very different artifacts. Today’s collection brings the scattered implementations together, from an SVG drawing to 3D coastlines with wind, scarves, waves, and fishing interactions.

This is an **artifact archive and implementation note for September 27, 2026**, not a controlled model benchmark. It does not rank generation speed, frame rate, or visual quality. File timestamps are not measurements of generation time.

## Three 3D experiments to open

Each page retains its own original controls and instructions. A desktop browser is a useful starting point. Mobile interaction and graphics support depend on the implementation and the device.

### 01 · Coastal Ride: a local experiment

[Open the local experiment](/experiments/pelican/frontier/index.html)

This implementation keeps its scene in a single HTML file and uses Three.js r160. Its source includes a coastal road, a world-space Verlet scarf, ocean shaders, a day–night cycle, fishing combos, five camera modes, fourteen achievements, and adaptive quality logic.

Its source is labeled **Frontier / local experiment**. The artifact is confirmed, but its creator app and model are not. It is therefore not attributed to DSH, and no model name has been guessed.

### 02 · Pelican After Dark: Codex

[Open Pelican After Dark](/experiments/pelican/codex/index.html)

Built with Three.js r170, this version combines cloth animation, day–night transitions, waves, and fishing. The source includes five cameras, fourteen achievements, Web Audio effects, an autopilot triggered after four idle seconds, and persistent touch controls.

The local session record has a model field of `gpt-6-luna`. This is a traceable record label, not an independent verification of the actual model behind the service.

### 03 · Island Coast Ride: WorkBuddy

[Open Island Coast Ride](/experiments/pelican/workbuddy/index.html)

This version separates the HTML interface from its scene script and uses a local Three.js r160 module. A circular CatmullRom track, swept terrain, custom ocean and tone-mapping code, and a local-space scarf distinguish its structure.

The source contains five camera modes, fourteen achievements, and four quality presets. Autopilot starts after seven idle seconds and can also be toggled with `R`. Its session-record model field is `deepseek-v4.1-flash`, again retained only as a source label.

## What changed during integration

The blog now includes the matching Three.js dependencies for all three 3D artifacts. Frontier’s module reference points to a local file. Codex’s r170 dependency is also local, and system fonts replace Google Fonts. WorkBuddy’s original HTML and scene script are unchanged.

These are dependency and font adaptations, not gameplay rewrites. The original artifacts remain intact and can be compared with their archive copies. Preserving provenance does not mean claiming every adapted file is byte-for-byte identical.

## Verification boundaries

All three sources contain genuine WebGL scenes, geometry, cameras, animation, and interaction logic, and their main scripts passed syntax checks. Different source contents and hashes confirm that they are separate implementations.

That evidence does not establish that every achievement can be unlocked, cloth stays stable indefinitely, every phone runs smoothly, or one model outperforms another. Graphics quality, frame rate, sound, and compatibility still need device-specific testing.

The point of this archive is to keep the artifacts, their sources, and their uncertainties together: preserve what was found, mark what is missing, and leave an honest starting point for the next iteration.
